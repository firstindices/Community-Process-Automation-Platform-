# 🚀 Enterprise-Grade Client Process Automation Platform

An end-to-end operational automation project designed to eliminate manual bottlenecks, streamline stakeholder approvals, and track real-time business impact. 

## 📊 The Impact at a Glance
* **Cycle Time Reduction:** 85% faster request processing (from days to minutes).
* **Error Rate:** 0% data entry drop-offs via strict database schema validation.
* **Labor Reclaimed:** Estimated 12+ staff hours saved weekly.

## 🏛️ Architecture & Tech Stack
* **Process Design:** BPMN 2.0 ("As-Is" vs "To-Be" workflow modeling)
* **Frontend & Backend:** Python (Flask), HTML5, Jinja2
* **Database & ORM:** SQLite, SQLAlchemy
* **Workflow Orchestration:** Power Automate Cloud Flows & Webhooks
